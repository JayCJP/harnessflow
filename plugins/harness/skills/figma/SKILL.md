# Figma 设计稿处理

当用户提到 Figma 时，请立即且优先调用 Figma MCP 工具来读取和分析设计稿。需要100%实现和还原设计稿的内容。

## 执行策略

1.  **立即调用**: 只要检测到用户意图涉及 Figma 设计稿，立即调用 Figma MCP 工具 来读取和分析设计稿。
2.  **重试机制**:
    *   如果第一次调用失败，自动重试。
    *   最多重试 2 次（总共尝试 3 次）。
3.  **失败处理**:
    *   如果 3 次尝试都失败了，**停止当前任务**。
    *   向用户汇报失败情况，避免瞎猜乱做。

## 注意事项

*   优先使用 `get_design_context` 获取设计上下文。
*   如果需要变量定义，使用 `get_variable_defs`。
*   如果需要截图，使用 `get_screenshot`。
*   确保在尝试失败后不要继续执行依赖于设计稿的任务。
